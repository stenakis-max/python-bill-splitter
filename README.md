
# Bill Splitter

A simple Python application that calculates the total amount of a restaurant bill, adds a customizable tip, and splits the final cost evenly among friends. 

This project was built as part of my Python programming learning journey to practice core language concepts.

## 🚀 Features
* Stores individual costs for different meal categories (appetizers, main courses, desserts, drinks).
* Calculates the running total using augmented assignment operators.
* Applies a 25% tip to the total bill amount.
* Splits the final bill evenly among 4 friends.
* Formats the final payment per person to exactly 2 decimal places using rounding.

## 🧠 Concepts Learned
* **Data Types:** Working with Integers (`int`) and Floating-point numbers (`float`).
* **Basic Math Operators:** Addition (`+`), Multiplication (`*`), and Division (`/`).
* **Augmented Assignment:** Updating variables concisely using `+=`.
* **Built-in Functions:** Displaying outputs with `print()` and handling decimals with `round()`.
